# StyleHub - Modern E-Commerce Web Application

A responsive, multi-page fashion e-commerce storefront built with HTML5, CSS3, JavaScript, and Bootstrap 4.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Shabna-002/first-repository)

## 🌟 Features
- **Responsive Navigation**: Categorized links for Men, Women, and Kids with mobile toggle.
- **Dynamic Shopping Cart**: Full cart state management with `localStorage`, quantity controls (+/-), subtotal calculation, discount rules, and free delivery thresholds.
- **Product Catalog**: Individual category pages (`men.html`, `women.html`, `kids.html`) with actual pricing, discount tags, and ratings.
- **Modals**: Sign In and Sign Up interactive dialogs with session simulated navbar greetings.
- **Modern Styling**: Google Poppins typography, FontAwesome 6 iconography, and smooth card elevation effects.

### Method 2: Render Dashboard
1. Go to [dashboard.render.com](https://dashboard.render.com/) and log in (with GitHub).
2. Click **New +** > **Static Site**.
3. Connect repository **`Shabna-002/first-repository`**.
4. Set configurations:
   - **Name**: `stylehub-ecommerce` (or any name you choose)
   - **Branch**: `main`
   - **Build Command**: *(leave empty)*
   - **Publish Directory**: `.`
5. Click **Create Static Site**.

# StyleHub - Modern Premium E-Commerce Platform

A production-grade, highly responsive, multi-page fashion e-commerce web platform built with modern HTML5, CSS3, JavaScript (ES6+), and Bootstrap.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Shabna-002/first-repository)

## 🌟 Pages & Key Features

1. **Homepage (`index.html` / `ecommerce.html`)**:
   - Modern brand identity with sticky navbar, live autocomplete search dropdown, and quick action icons (Wishlist, Cart, Profile).
   - High-definition hero carousel with gradient overlays & category call-to-actions.
   - Value propositions / trust bar (Free delivery, genuine brands, 30-day returns, 24/7 care).
   - Category tiles for Men, Women, and Kids with hover elevation.
   - Tabbed collections: **Featured**, **Trending**, **New Arrivals**, and **Best Sellers**.
   - Deal of the Day section with **live countdown timer** (Hours : Mins : Secs).
   - Verified customer reviews & testimonials.
   - Newsletter subscription card with instant ₹300 coupon feedback.
   - Enterprise footer with links, payment method badges, and security credentials.

2. **Catalog & Advanced Filtering (`shop.html`)**:
   - Category filtering (All, Men, Women, Kids).
   - Real-time price range slider (₹400 – ₹5,000).
   - Star rating filtering (4.0★, 4.5★+).
   - Sorting options: Price (Low to High / High to Low), Highest Rated, and Biggest Discounts.
   - Search query synchronization.

3. **Product Details Page (`product-detail.html`)**:
   - Multi-image gallery with active thumbnail selector.
   - Pricing with strikethrough MRP and discount percentage badge.
   - Size selector (S, M, L, XL, XXL) with interactive modal size chart.
   - Quantity selector (+ / -).
   - Postal pincode delivery checker with estimated delivery timeframe.
   - Quick Add to Cart, Buy Now, and Wishlist toggling.
   - Related products carousel.

4. **Dynamic Shopping Cart (`cart.html`)**:
   - Cart item list with thumbnail, title, size/color variant, and unit price.
   - Quantity controls with live total computation.
   - Move to Wishlist and item removal.
   - Real coupon code system (`WELCOME10` for 10% off, `STYLE20` for 20% off, `FLAT300` for ₹300 off).
   - Free shipping progress bar (unlocks at ₹999).
   - Sticky order summary breakdown.

5. **Multi-Step Checkout (`checkout.html`)**:
   - Stepper wizard: Customer Info -> Shipping Address -> Payment Method -> Confirmation.
   - Form validation for phone numbers, email, and postal code.
   - Payment modes: UPI (GPay, PhonePe, Paytm), Credit/Debit Cards, Cash on Delivery (COD).
   - Instant order creation with unique Order ID (`SH-xxxxx`), estimated delivery date, and order tracking shortcut.

6. **Customer Wishlist (`wishlist.html`)**:
   - Grid of saved products with live count badges.
   - Quick "Move to Cart" button.
   - Empty state view with direct store navigation.

7. **Authentication (`auth.html`)**:
   - Modern glassmorphism split-tab card (Sign In / Register).
   - Password show/hide eye toggle.
   - Remember me checkbox and Forgot Password modal.
   - Social login buttons (Google, Apple, Facebook).

8. **Customer Dashboard (`dashboard.html`)**:
   - User profile overview with joined date and contact details.
   - Order history table with status badges (Processing, Delivered) and tracking links.
   - Saved delivery addresses management.

9. **Live Order Tracking (`order-tracking.html`)**:
   - Visual vertical timeline stepper: Order Placed -> Packed -> Shipped -> Out for Delivery -> Delivered.
   - Package contents breakdown and courier details.

10. **Admin Dashboard (`admin.html`)**:
    - KPI metric cards: Total Revenue, Total Orders, Active Products, Registered Users.
    - Monthly sales trend chart.
    - Product Inventory management with **Add Product modal** and **Delete** actions.
    - Order management with one-click status toggle (Processing <-> Delivered).
